# Высокопроизводительный асинхронный сервис мониторинга доменов

## Установка

### Для пользователя
```bash
pip install .
```

### Для разработчика (с тестами и линтерами)
```bash
pip install -e ".[dev]"
```

## Запуск
Сервис устанавливается как системная команда. Передайте путь к файлу с доменами в качестве аргумента:
```bash
monitor-run domains_full.txt
```

## Тестирование

### Запуск всех тестов
```bash
pytest
```

### Запуск с метриками покрытия кода
```bash
pytest --cov=src --cov-report=term-missing
```

## Код-стайл
Проверка соответствия PEP 8 с помощью Ruff:
```bash
ruff check .
```
